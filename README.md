# Athena
Athena est un système logiciel e-commerce complet, conçu et réalisé par Armel Tchokothe dans le cadre de son parcours d'ingénieur logiciel. Le modèle de référence est Glothelo (vente d'appareils électroniques), avec un périmètre plus large : vente en ligne, vente mobile, vente en boutique physique et analyse des données.
